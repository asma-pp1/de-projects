# Airbnb Listings Analysis — Paris

## Overview

A Python data analysis project from Maven Analytics platform. The goal is to explore Airbnb listings in Paris, analyze pricing patterns, and examine changes in new hosts over time.

## Objectives

* **Data Profiling & Quality:** Inspect the dataset, convert date columns, filter Paris listings, and check missing values and descriptive statistics.
* **Data Preparation:** Calculate average prices by neighbourhood, accommodation capacity, and host registration year.
* **Visualization & Insights:** Create bar charts and line charts to explore pricing trends and changes in the number of new hosts.

## Tools & Libraries

* Python
* Jupyter Notebook
* Pandas
* Matplotlib

## Key Questions

* How do average listing prices vary across Paris neighbourhoods?
* How does accommodation capacity relate to average price in the most expensive neighbourhood?
* How have new hosts and average prices changed over time?
* What patterns can be observed around the 2015 regulations?

## Dataset

Source: Maven Analytics Airbnb Listings challenge.

The original listings dataset is not included in this repository because of its large file size. Obtain the dataset from Maven Analytics platform and place `Listings.csv` in the `data/` folder before running the notebook.
